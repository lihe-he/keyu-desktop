# 0.1.5 第七候选 · 本机实测步骤

更新日期：2026-11-12。本轮先验证学习通的真实课程打开与章节读取。代码回归与真实平台结果分别记录；以下步骤尚未由用户执行，不表示验收通过。

## 切换到本轮候选

1. 在当前网课助手窗口点击左侧“记录与设置”，再点击“应用设置”。滚动到底部，点击“完全退出应用 → 保存并退出”。窗口右上角的关闭按钮默认只隐藏到托盘。
2. 打开项目内 `release/candidate-0.1.5-r7/win-unpacked/CampusCourseDesktop.exe`。保留同目录的全部文件。此次使用免安装程序，账号和课程记录仍使用原本的本机数据目录。
3. 在左下角或“记录与设置 → 应用设置”确认显示版本 `0.1.5`。同一版本的候选编号以启动目录 `candidate-0.1.5-r7` 为准。

## 先验证学习通课程打开

1. 点击“账号管理”，找到已有学习通账号，点击该卡片的“打开登录”。如果没有本地账号卡片，点击“添加账号”，选择学习通并填写便于辨认的备注，再点“添加并打开登录”。
2. 如果平台要求登录，由你在平台原页自行完成。手机确认后如页面没有跳转，点击工作台的“手机已确认，核对登录”。密码、验证码和二维码只在平台原页使用。
3. 在学习通网页自己的菜单点击“课程 → 我学的课”，确认已出现课程封面；个人空间的周课表不是这一步的课程目录。
4. 点击助手左侧“我的课程”，选择刚才的学习通账号，点击右上角“刷新所选账号”。记录提示中的课程数量。
5. 在一门可访问的课程卡片上点击“打开原页”。确认“学习工作台”中出现该课程目录。遇到登录、网络、跳转或访问限制提示时，记录提示原文。
6. 如果课程原页打开，点击助手左侧“我的课程”，在同一张课程卡片上点击“选择章节”。记录是否弹出章节列表、章节数量和顺序是否与平台页面一致。

第一轮回报只需要以下事实，不需要真实课名、账号、学校或完整网页地址：

```text
启动目录：candidate-0.1.5-r7
登录：进入个人空间 / 仍要求登录 / 其他现象
刷新课程：__ 门 / 失败提示原文
打开原页：看到课程目录 / 失败提示原文
选择章节：__ 个，与原页一致 / 失败提示原文
```

右上角铃铛及“记录与设置 → 学习提醒”中会保留导航拦截消息。失败时可抄录最新消息；不要将地址参数、签名、Cookie、密码或验证码附在回报里。

## 章节读到后再验证真实播放

1. 在“选择章节”弹窗中只勾选按原顺序连续的两个可进入视频章节，点击“加入学习队列”。平台显示未解锁、答题、考试或作业的章节留待人工处理。
2. 点击左侧“任务中心”，在学习通的平台通道点击“启动队列”。到“学习工作台”核对当前章节与平台视频一致，时间在正常前进；平台要求手动播放时，由你点击原页播放按钮。
3. 等待第一个真实视频自然结束，记录是否只在第二章允许进入时才切换。分别记录“本地播放已结束”和“平台已确认完成 / 平台完成状态待确认”，两者不能互相代替。
4. 在本机使用暂停、恢复、托盘及重启操作，观察是否重新核对页面。验证码、身份验证和题目由你在平台处理，保留应用显示的暂停原因。
5. 完成后按第一节的“保存并退出”正常退出，回复实际结果。下一轮代码与安装检查可在应用退出后继续，不需要卸载或清空账号数据。

## 其余首版验收

中国大学 MOOC 普通选课与智慧树共享学分课仍需各自完成原页登录、真实目录、连续两章播放与完成状态、双账号隔离和异常恢复。逐项记录格式见 [真实平台兼容性报告](真实平台兼容性报告.md)。

三平台真实课程连续运行两小时，以及独立干净 Windows 10/11 的安装、重装、跨版本升级和卸载仍是必要条件。干净系统操作见 [干净 Windows 验收](干净Windows验收.md)；不要用开发机短时夹具结果填写真实课程或干净系统的通过项。
