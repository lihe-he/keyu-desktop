# 版本记录

## 0.1.5 · 开发中，尚未发布（2026-11-05 起，2026-11-12 更新）

- 复现 0.1.4 登录后真实个人课程读取失败；补充学习通 `#courseList` 内课程标题链接和 `stucoursemiddle` 地址模式，保留原读取规则。
- 只导入标题链接，不将封面、教师或“课程已结束”当课程名；“课程已结束”不等于平台确认学习完成。
- 工作台小房子明确标为“打开学习通个人空间”，增加“课表不是网课目录”的操作提示。
- 增加脱敏结构单元测试和跨域嵌套课程页桌面回归；不保存用户页面、个人信息或真实课程地址参数。
- 11 月 5 日复测发现第二套 v24 目录，第一候选仍读取失败。补充 `#stuCourseList` 标题识别及当前目录临时入口解析，课程定位不包含签名；课程窗口在当前账号页面打开。
- 用户反馈需要扫码两次才进入，增加“手机已确认，核对登录”入口及区分 HTTP 跳转和页面加载失败的提示；用户随后确认一次扫码后点按钮可以进入。自动跳转和重启保持仍未通过。
- 第二候选实机已导入 20 门真实课程；课程打开时仍有加载失败及 HTTP 拦截，章节与播放未通过。151 项单元、6 项桌面回归及第二候选启动 / 公开入口检查通过；短时合成耐久仍是旧候选历史结果。
- 第三候选细分主页面、嵌套页面、导航、新窗口与服务端重定向，只展示固定站点和路径标签，不保存完整地址、编号或签名；本次课程请求失败时返回实际拦截原因，避免误导用户重新扫码。158 项单元、7 项桌面流程及第三候选启动 / 官方未登录入口检查通过。真实课程打开问题仍待本机核对，不把新增诊断当作适配完成。
- 第三候选实机定位到课程入口的旧 HTTP 主页面重定向。第四候选只对当前 v24 签名入口返回的精确课程站点与路径尝试一次 HTTPS；循环、其他路径和登录跳转继续停止。170 项单元与 9 项桌面回归通过，真实认证课程仍待核对；没有借此认定章节或播放成功。
- 第五候选修复超时后旧页面仍加载、HTTPS 重试中取消操作被误报为网络失败，以及旧请求保留重试资格的问题；账号、任务和导航归属改变后撤销原操作。
- 章节按原页 DOM 顺序读取，排除包含子章节的分组；同名不同控件保留独立身份，播放器与当前章节的核对覆盖这些身份。分组自身的禁用限制仍由子章节继承，完成状态和兄弟锁分别核对。
- 隐藏或矛盾的完成标记不产生“已完成”；多处激活章节不能可靠对应时停止自动推进。
- 源码打包核对完整桌面报告的实际执行和统计，允许测试数量增长，拒绝失败、跳过、重试和残缺报告。补充独立 Windows 10/11 的验收材料，准备材料不代表执行成功。
- 第六候选增加文档代次检查，第七候选补齐主页面内跳转时的课程解绑和嵌套页面读取完整性。导航、同地址刷新、关闭或任务替换期间的旧课程入口、章节与播放结果不能继续使用；无法读取一个允许框架时停止本次读取。244 项单元及 10 项桌面流程通过，真实平台结果仍待用户按本机实测步骤反馈。
- 构建一致性检查默认读取当前候选目录相邻的安装包，并记录具体路径，防止相同开发版本号下误取旧候选包。
- 修复用户先点“打开原页”再点“选择章节”时重复请求课程入口的界面流程。章节按钮只请求主进程读取，主进程保留已核对的当前课程页面；v24 夹具回归直接点击界面按钮验证，不复用旧签名。
- 第八候选修复用户报告的 A → B 仍回到 A：在当前账号会话中保留一份 v24 目录文档，课程页单独复用，每次切换重新解析目录中的对应入口；反复切换不累积页面，开始任务、切换账号或关闭页面时释放目录。
- 普通课程新窗口在当前账号页面导航，认证站点才复用登录弹窗，复用时加载本次请求的地址。旧账号或保留在后台的目录不能通过新窗口请求改变当前账号课程。
- 学习通跳转后核对课程标识，错误课程、歧义标识或无法核对的 v24 目标不绑定、不读取为所选课程。打开失败保持课程列表和错误提示；重复打开当前课程保留已核对页面，首次课程页面后退可返回保留目录。
- 277 项单元、13 项完整桌面流程通过；新增双课程夹具分别验证 A → B → A、目录签名更新、各自的章节、错误跳转与资源释放。第八候选真实课程结果仍待用户按本机步骤反馈。
- 新版本安装验收尚未完成。只推送开发修复，不覆盖旧发布，不创建 0.1.5 发布附件。
