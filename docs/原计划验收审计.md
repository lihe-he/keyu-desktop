## 下一步需要的真实输入

用户在本机的应用原页分别登录三个平台，各选择一门范围内课程和连续两个可进入视频章节，按真实兼容性报告执行。账号密码和验证码不要通过聊天传递。此输入缺失时，新增合成测试不能证明真实适配完成。

另外需要干净 Windows 10/11 x64 测试机，以及真实课程两小时运行的时间窗口。没有这些环境 / 证据，目标保持未完成。
