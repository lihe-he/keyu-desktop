# 开发与架构

代码版本：0.1.5 开发中（尚未发布）；Windows 本地桌面单项目。依赖具体版本见 package.json 和 pnpm-lock.yaml。

## 1. 模块

- `src/renderer/src/`：Vue 3 + Pinia 六页面。展示状态和发送明确命令，不维护独立调度器。
- `src/shared/`：跨进程契约、Zod 输入验证、候选平台范围和域名名单。
- `src/preload/index.ts`：只给自有界面暴露窄通信桥；第三方页面使用独立无公开接口的 preload。
- `src/main/index.ts`：窗口、托盘、系统事件、命令入口、快照、账号操作互斥、诊断。
- `src/main/core/engine.ts`：三个独立平台通道，任务身份和 generation 防止旧结果推进。
- `src/main/runtime.ts`：WebContentsView 生命周期、持久 Session 分区、音频、导航 / 权限与登录窗口控制。
- `src/main/adapters/`：三个候选 recipe 共用受约束的 DOM 观测、控制与结果校验。
- `src/main/store.ts`：better-sqlite3，SQLite v1 迁移、WAL、外键关联清理、有限日志 / 通知。
- `src/main/core/reminders.ts`：仅本机每日 / 休息提醒；启用或改时间后重新起算，跨天未执行提醒合并，关闭程序没有通知服务。

## 2. 本地开发

建议使用与本轮一致的 Node 24 x64、pnpm 12。原生模块没有可用预编译包时，需要 Python 和 Visual Studio C++ 编译工具；这些只用于构建，不是终端用户运行条件。

```powershell
pnpm install --frozen-lockfile
pnpm typecheck
pnpm test
pnpm test:e2e
pnpm dev
pnpm dist
```

依赖安装后的 `electron-builder install-app-deps` 会为 Electron 重建 better-sqlite3；不要用 Node 的 ABI 替换最终 Electron 模块。SQLite 单元测试会在 Electron 的 Node 模式中执行，避免用宿主 Node 错配的原生 ABI。

Electron 网络下载失败时，可运行 `node scripts/ensure-electron.cjs`：从固定版本的官方发布地址下载并校验对应 SHA-256。不要禁用 TLS 或浏览器安全。构建使用 `electronDist` 指向经过校验的本地 Electron。

```powershell

pnpm test:e2e
# 默认合成媒体两小时测试；不是三平台实课验收

node scripts/packaged-smoke.cjs release/build-0.1.5/win-unpacked/CampusCourseDesktop.exe

```

开发模式可用 `CAMPUS_USER_DATA` 指定绝对测试数据目录。只有未打包且 `CAMPUS_TEST_MODE=1` 才启用夹具；生产包忽略这两个环境变量，不提供全局测试钩子。0.1.4 起，校验脚本生成 UUID 并传入本地启动参数 `--campus-verification-profile`，仅把数据位置改为系统临时目录下的专用 UUID 子目录；不会开启模拟网页、任意脚本或 IPC，日常启动仍使用原数据目录。非法标识会终止启动而非回退到日常账号。脚本在增删测试数据前核对实际隔离路径。不要把 `.test-data`、用户数据、Cookie 或浏览器配置作为源码交付。

`tests/e2e/desktop.spec.ts` 包含 Windows 自有窗口截图，不能拿测试截图证明平台兼容。

## 4. 安全和状态不变量

- 自有界面 IPC 同时核对 WebContents 身份、主框架和来源 URL，命令严格验证；不接受任意脚本 / 路径。
- 第三方页面关闭 Node、启用上下文隔离 / 沙箱 / webSecurity；不授予设备权限，不允许任意弹窗和非名单导航。
- 独立持久 Session 按平台与本地账号 ID 哈希分区；账号删除先停止任务再清会话与关联记录。
- 浏览 / 登录模式不属于学习任务，默认禁止媒体请求并暂停媒体；任务由主进程调度。
- 同平台同一时刻只存在一个任务页面；暂停和待处理任务保留通道，待执行任务不预加载。
- 播放页返回的观测须匹配任务、账号、章节、generation、观测时间；无效或旧结果不推进。
- 恢复不根据旧时间强制跳转；先重开、核对章节与播放器，再正常播放。
- 页面隐藏不伪装 visibility；停止或停滞时暂停提示，不保证平台后台播放。
- SQLite 不保存密码 / Cookie / token；会话仍属于敏感本机资料。课程地址拒绝明显鉴权参数，诊断只含筛选字段和脱敏信息；这不是任意网页内容的通用秘密识别器。
- 学习通 v24 目录的签名入口仅在内存使用；持久化角色、课程、班级及上下文编号作为定位，打开时从当前账号可见目录重新解析，拒绝未知参数、歧义或页面切换后的结果。无签名定位不是导航地址。章节与任务地址继续通过凭据过滤。
- v24 签名入口的主页面服务端重定向若指向已观察到的 `http://mooc1.chaoxing.com/visit/stucoursemiddle`，先阻止 HTTP，再用相同参数尝试一次 HTTPS。仅此固定站点与路径，无用户名、密码、非默认端口或片段；不处理登录、子框架、其他路径或其他平台，不循环重试。临时地址不写入记录，过期页面操作不触发重试。公开 HTTPS 端点已验证 TLS 与 GET 响应，认证后兼容性仍需实测。
- 学习通登录页的“手机已确认，核对登录”只调用现有固定 HTTPS 个人空间导航，不写登录状态；离开登录页隐藏。用户已确认手动核对路径，自动跳转及重启保持未通过。
- 累计媒体播放与不重复观察区间分别汇总；不能声明为个人有效学习时间或平台学分。

## 5. 如何完成真实平台适配

三个 recipe 是**未验证候选实现**，不是来自已获授权的真实课程验收样本。不能仅修改 UI 的验证标识来宣称支持。

1. 用户在本机官方原页登录，选择范围内自己的课程，不将凭据发到聊天。
2. 记录可见目录、当前章节、唯一播放器、解锁和完成标记的非敏感结构。
3. 先加入去标识的解析回归样本，再调整 recipes / probe；核对正常 iframe 页面。顶层使用 isolated world；子框架没有相同隔离执行接口，只执行固定探针，不暴露本机能力，读取结果按不可信输入校验。
4. 用同一个调度器完成两段视频；无法确定章节身份 / 解锁 / 当前完成状态就暂停，不读私有接口或制造完成请求。
5. 合法登录重定向域名只有经过真实证据验证才加入名单，不开放通配全网。
6. 将成功与失败分别写入兼容性报告，完成真实账号隔离 / 异常 / 两小时验收后再调整平台能力声明。

受保护播放器、学校定制、需要直接手势播放、嵌套目录依赖父页面上下文等仍有兼容性风险。发现这些情况时修复正常流程或记录不兼容，不绕过平台限制。

## 6. 发布

NSIS 按当前用户安装，默认保留数据，手动更新；没有自动遥测 / 更新服务器。未做发布者签名。

`pnpm dist` 输出安装包及完整 win-unpacked 文件夹，docs 同时随程序分发。最终构建完成后运行 `python scripts/source-bundle.py` 生成源码 ZIP、交付清单和 SHA256SUMS.txt；此步骤不包含 node_modules、会话、缓存、测试数据或安装目录。

全量源码、锁文件和测试都在源码 ZIP 中；第三方二进制声明位于完整应用目录。源码沿用仓库已有 MIT License；package.json 的 private 仅禁止意外发布 npm 包。公开分发前仍需确认第三方许可义务。

旧程序仍运行时，使用 `electron-builder --config.directories.output=release/build-0.1.5` 输出到独立目录，不覆盖运行中的文件；校验脚本必须显式传对应 exe / win-unpacked 路径，不使用残留的旧 `release/win-unpacked`。0.1.5 安装预检发现用户程序正在运行，未执行安装；本机已有正式安装，退出后也不能为校验卸载它。0.1.4 安装历史仅测试同版本重装；不使用不能隔离数据的旧版程序访问日常账号。完成当前版本所有发布校验前，不运行源码打包或创建 Release。
