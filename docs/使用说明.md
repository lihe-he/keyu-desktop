# 网课助手使用说明（0.1.4 已发布 / 0.1.5 开发中）

适用：Windows 开发预览版。目标系统为 Windows 10/11 x64；实际测试环境和未完成项目见测试报告。

## 1. 安装与启动

1. 核对 release/SHA256SUMS.txt 中的安装包校验值。
2. 双击 CampusCourseDesktop-Setup-0.1.4-x64.exe，按当前 Windows 用户安装。
3. 安装完成后，从开始菜单或桌面快捷方式打开“网课助手”。
4. 此预览版未做发布者签名。若系统给出安全提示，先核对来源与校验值；不要关闭系统安全功能。

应用运行本身不要求安装 Node、Java 或数据库开发工具。免安装试用时，必须保留 win-unpacked 中的所有文件，不能只复制 exe。

## 2. 第一次使用

1. 打开“账号管理”，点击“添加账号”，选平台并填写备注。
2. 进入“学习工作台”的平台原始页面，在那里自行输入账号、密码、验证码。
3. 学习通登录后，在**学习通网页自己的菜单**中点“课程”，看到“我学的课”和课程封面才是网课目录；“课表”显示的是周课表，不能导入网课。小房子按钮只打开个人空间：0.1.4 误标为“打开我的课程入口”，0.1.5 改为“打开学习通个人空间”。其他平台通过原页进入个人课程列表。
4. 回到“我的课程”，选中本地账号，点击“刷新所选账号”。
5. 点击课程的“选择章节”，核对识别到的章节与平台页面一致，再加入队列。
6. 在“任务中心”启动对应平台的队列。未经你启动，不会自动开始课程。

**首版三个平台都标为“待真实课程验证”。** 0.1.5 第二候选已在一个真实学习通账号导入 20 门课程，但课程打开及章节读取仍失败，不能认定可执行学习任务。v24 课程打开需要当前账号原页仍在“我学的课”；应用从目录取得临时入口，不保存或复用旧签名。如果目录无法识别、登录跳转被拦截或播放器不支持，应用会提示。请保留报错并联系开发者，不要反复刷新或尝试绕过限制。

2026-11-11 第五候选补充了导航取消、章节顺序及目标核对修复。选择章节时应与原页顺序一致，同名章节分别展示；目录链接、解锁状态或当前目标已改变时，需要重新读取。隐藏或矛盾的完成标记保持“待确认”。本轮自动验证不能替代实际课程结果。

## 3. 同时学习与账号隔离

- 每个平台最多一个任务。同平台的另一个账号在队列里等待。
- 切换界面账号不会改绑已经启动的任务。
- 暂停 / 待处理任务会保留该平台通道。要继续别的任务，需要恢复或取消当前任务。
- 默认只有学习通通道可发声；在工作台选择“让当前平台发声”可切换。也可全部静音。
- 浏览 / 登录模式不执行学习任务，不应依靠它额外播放。

工作台右侧会显示本次任务的章节列表、当前章节及各章平台完成状态；可收起列表扩大原始网页。暂停后列表仍保留，点击“确认恢复”重新核对，不提供直接跳章按钮。

## 4. 状态怎么理解

| 状态 | 含义 |
|---|---|
| 待执行 | 在队列中，不加载播放页 |
| 执行中 | 当前任务已启动；实际播放、缓冲或待核对状态在工作台单独显示 |
| 已暂停 | 用户暂停，需要确认恢复 |
| 需要处理 | 登录失效、验证码、答题、未解锁、网络或页面结构异常 |
| 待确认恢复 | 应用异常退出、重启或电脑休眠后留下的任务 |
| 本地播放结束 | 观察到所选视频结束；不必然等于平台判定课程完成 |
| 平台确认完成 | 读取到明确的当前章节完成标记；整项任务所有所选章节均确认才汇总为完成 |

时长是应用观察值，不是学分或平台认可时长。三路播放产生的累计时长与重叠去重后的观察时间分别显示；并发时间不能混称为个人有效学习时长。

## 5. 异常、休眠与托盘

- 遇到登录、验证码、人工答题或身份确认，在原始平台页面自行处理。
- 不会自动回答或提交，也不会跳过锁定章节。
- 恢复任务时会重开 / 核对页面，不会凭旧检查点强制跳到旧进度。
- 修改页面章节、无法核对播放器所属章节、结束状态与时长不符时暂停。
- 短暂读取失败有限重试；连续三次失败转为待处理。
- 关闭主窗口默认进入托盘。平台如果停止后台播放，应用会在检查到后提示，不伪装可见性。
- 电脑唤醒后需要你确认继续。完全退出后没有后台执行或提醒服务。
- 托盘菜单可重新打开、暂停全部任务或完全退出。

## 6. 提醒、隐私与删除

- 在“记录与设置”手动启用每日学习或休息间隔提醒。不会根据提醒自动启动课程。
- 错过的提醒在重新打开时汇总；系统通知能否显示还受 Windows 通知设置影响。
- 删除账号先停止它的任务，再清理该账号的会话、课程与记录，不注销平台账号，不影响其他本地账号。
- “清理历史”删除已结束 / 已取消任务及历史记录；未完成任务和账号保留。
- 诊断导出不包含账号备注、课程标题、页面内容、Cookie 或访问令牌。发送前仍建议自行检查。
- 卸载默认保留本地数据以便重装；若要删除会话，应先在应用内删除账号。不要直接把整个数据目录作为诊断文件发送。

## 7. 真实课程验收需要你做什么

在本机分别登录学习通、中国大学 MOOC 和智慧树，每个平台准备一门范围内的课程及连续两个允许进入的视频章节。密码和验证码只输入平台原页，**不要发到聊天里**。按兼容性报告逐项核对；通过前只适合小范围手动试用。

## 8. 学习通扫码确认后仍停在登录页

0.1.4 固定了官方登录页的 HTTPS 返回地址，但 0.1.5 复测仍出现首次扫码确认未跳转。0.1.5 第二候选在学习通登录页上方提供“手机已确认，核对登录”：自行扫码一次并在手机确认后，若页面未跳转，点击该按钮检查同一账号的个人空间，无需先重复扫码。已有用户确认点按钮可进入，但自动跳转与重启保持仍未通过。

若进入个人空间，继续点平台自己的“课程”再刷新助手课程。若仍要求登录、出现拦截或错误提示，保留提示文字；不要删除账号、清空会话或发送密码、验证码、完整鉴权网址。课程打开阶段出现的 HTTP 拦截另行核查，不等于需要重新扫码。
