## 单元测试覆盖

- 任务引擎 46 项：三平台通道、同平台排队、暂停占用、取消及取消竞态、过期结果、结束状态与时长一致性、平台未知完成标记、断点恢复、休眠、有限失败重试、媒体时钟停滞等。
- 安全与输入校验 50 项：来源身份、主框架、域名后缀边界、HTTPS、恶意地址与含凭据课程地址、参数约束及脱敏；新增签名拒绝、v24 稳定定位与字段边界。
- 观察时长与提醒 13 项：重叠去重、截断、真实零值、休息间隔、跨天提醒汇总、重新启用和修改时间的起算边界、回拨时钟、旧设置兼容。
- 页面解析 22 项：可见目录、章节、锁定、人工操作、登录 / 验证、完成标记及播放器；学习通两套个人课程容器、标题 / 封面去重、结束提示、周课表排除等回归。使用脱敏重建的受控 DOM，不是真实账号页面。
- 课程入口解析 3 项：签名轮换不改变课程身份、签名仅从当前目录解析、缺目录 / 错编号 / 登录要求 / 入口歧义时拒绝。
- SQLite 6 项：使用实际 Electron 原生数据库模块执行，覆盖持久化、删除关联、迁移版本保护、设置与记录。
- 官方入口配置 2 项：智慧树直接地址、现有域名名单与“未验证”标识不变。
- 校验目录 6 项：只允许 UUID 对应的专用临时目录，路径穿越和任意目录输入被拒绝。
- 界面状态 3 项：快照先后顺序、可传输命令、叠加对话框管理。
- 导航诊断与限定 HTTPS 重试 19 项：区分主页面与嵌套页面、导航与服务端重定向；只输出固定站点和路径标签，拒绝回显未知地址、签名或原始错误文本；课程错误不建议重新扫码。精确课程入口可单次尝试 HTTPS，其他平台、入口、未签名请求、未知域名、路径或 URL 用户信息等不触发。

## 桌面自动流程

1. 三个平台测试夹具的双章节真实 HTML 媒体事件、平台模拟完成标记、观察时长、同平台账号分区、删除隔离、重启持久化；测试网页拿不到 Node 和应用通信桥。学习通改用跨域 iframe 内的 `#courseList` 标题链接，检查地址属于课程框架，不含上下文参数或教师名。
2. 六个页面的实际按钮 / 表单流程、课程选择、任务暂停恢复、对话框与原生页面隐藏、工作台章节列表折叠、暂停保留章节 / 恢复、实际播放器状态、1080×720 小窗口布局。
3. 模拟登录失效只暂停一个平台；人工解除后恢复；休眠事件与强制结束后进入待确认恢复，不自动播放。
4. 学习通登录入口显式 HTTPS 返回，实际界面“手机已确认，核对登录”按钮导航至固定个人空间，离开登录页后隐藏；旧 HTTP 与外站仍被阻止。覆盖非法命令、账号删除和清理历史边界。此项扫码确认以合成跳转模拟，真实用户反馈另列兼容性报告。
5. 删除同平台排队账号后，正在执行的账号及后续队列继续；删除正在执行的账号后，只停止该账号，下一账号正常启动并保持会话隔离。
6. v24 签名目录导入、从当前目录取得原始入口、读取章节、目录新窗口仍在当前账号浏览页面中打开；数据库与快照不保存签名或上下文令牌。夹具刻意拒绝无签名入口，不能代替真实课程跳转验收。
7. 签名课程入口重定向至 HTTP 时仍阻止，界面获得本次主页面重定向原因；不包含课程编号、签名或登录核对建议，不创建任务。该项为假数据，不证明真实平台使用相同跳转链。
8. 已观察到的 v24 旧入口重定向，阻止 HTTP 后单次尝试 HTTPS，再进入测试课程并读取双章节；通知、课程和日志不保存临时参数。
9. HTTPS 重试再次返回旧 HTTP 地址时，只发起一次 HTTPS 尝试并停止；不创建任务，不保留签名。上述两项仍是合成回归，真实课程结果另列。

测试网页和媒体只在未打包应用且显式启用测试模式时可用，屏幕带明显测试标识。测试媒体是本地生成的 8 秒静音 WAV，由 HTML 媒体元素播放，不是伪造时钟；它不能证明平台视频编码、加密播放器、登录或真实完成判定兼容。

## 短时资源检查

合成媒体三通道循环运行，轮流显示 / 隐藏平台页面，采样进程与内存。运行期间检查共 4 个 WebContents（自有界面 + 3 个平台页面）；取消所有任务后恢复为 1 个。内存采样仅供后续趋势比对，不据此宣称不存在内存泄漏。

默认 `pnpm test:soak` 可运行两小时的合成测试；报告中的约两分钟结果来自 11 月 4 日旧候选。11 月 5 日第四候选未重跑，不外推当前构建资源稳定性。真实平台的两小时验收仍需真实课程，不可替代。
